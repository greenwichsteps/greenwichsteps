## Projects

**Saturn Steps: a relationship CRM run by an AI agent**
A company-first CRM for deal-flow-style pipelines, with an MCP server so
Claude operates it day to day. It sources companies from funding news,
screens them against a written thesis, drafts outreach for me to send, logs
every email and meeting, and keeps a ranked next-action list. It models what
off-the-shelf CRMs don't: intro-shaped pipeline stages, a favor budget per
contact, prep notes with an approval step, and an undo log on every change.

**Burnside Steps: website feedback built for AI agents**
Add one `<script>` tag to any site, and visitors can pin a comment on the
page and annotate a screenshot. Each one arrives as a real issue in Linear,
GitHub, or GitLab, with the screenshot, the console log, and the exact
viewport attached, so your agents can pick it up from the tracker they
already read.

**Farnsworth Steps: Gmail, as a real Mac app**
A native macOS client built on the Gmail API rather than IMAP, so labels,
filters, drafts, and stars work exactly as they do in Gmail and stay in your
Google account, not in the app. Swift and SwiftUI. Heading into a closed beta.
